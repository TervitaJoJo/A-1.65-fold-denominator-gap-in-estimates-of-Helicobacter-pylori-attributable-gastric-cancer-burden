# Results

Runtime outputs are excluded from version control. A run writes:

- `primary_results.csv`: point estimates under the 50/50 and 70/30 subtype scenarios;
- `age_specific_details.csv`: intermediate prevalence, PAF, incidence, and attributable counts;
- `deterministic_sensitivity.csv`: all extraction and assumption checks;
- `contour_internal_check.csv`: agreement with labelled contours in the published graphic;
- `analysis_audit.json`: input-independent audit fields and summary statistics.
